# Kenga за 15 минут

Мини-курс из 7 программ: от `println(42)` до списков. Каждый урок — один файл
в `examples/tour/`, читается сверху вниз, комментарии в файле объясняют синтаксис.
Теория и точные правила — в `docs/SPEC.md`.

## 0. Запуск

Нужен собранный bootstrap-раннер (чистый C99, без Rust):

```bat
bootstrap\build.cmd
```

```bash
bash bootstrap/build.sh
```

(нужен любой C-компилятор: MSVC / gcc / clang). Затем из корня репозитория:

```bat
bootstrap\bin\kenga-lite.exe run examples\tour\01_hello.kenga
```

```bash
./bootstrap/bin/kenga-lite.exe run examples/tour/01_hello.kenga
```

Если раннер уже собран — шаг сборки пропускается. Есть и полный путь через
Rust (`kenga run file.kenga`), но для тура достаточно lite.

## Урок 1 — Hello, Kenga!

`examples/tour/01_hello.kenga`

```kenga
fn main() -> i64 {
    println(42);
    return 0;
}
```

Вся программа — функция `main`; `return 0` = успешное завершение.

Вывод:

```
42
```

## Урок 2 — переменные и арифметика

`examples/tour/02_vars.kenga`

`let` объявляет переменную (тип можно указать, можно вывести);
повторное присваивание — без `let`. Арифметика `+ - * / %` целочисленная.

Вывод:

```
6
42
48
```

## Урок 3 — функции

`examples/tour/03_fn.kenga`

Функции объявляются через `fn`, вызываются по имени; рекурсия разрешена.
Обратите внимание: `quad` вызывает `double`, которая объявлена **ниже** —
порядок определений не важен, kenga-lite собирает все имена до компиляции тел.

Вывод:

```
42
84
```

## Урок 4 — ветвление

`examples/tour/04_if.kenga`

`if cond { ... } else { ... }`; условие истинно, когда не равно 0;
результат сравнения — это 0 или 1. Классический `max` из двух:

Вывод:

```
10
10
```

## Урок 5 — цикл while

`examples/tour/05_while.kenga`

Сумма чисел от 1 до n: счётчик и аккумулятор обновляются вручную.
`while` работает во всех диалектах Kenga, включая self-host компилятор,
поэтому именно он — базовый цикл языка (`for` тоже есть, см. `docs/SPEC.md` §5).

Вывод:

```
5050
```

## Урок 6 — строки

`examples/tour/06_strings.kenga`

Конкатенация — обычный `+`, длина — `len(s)`, сравнение — `==`.
`s[i]` возвращает **строку из одного символа** (не число); код символа — `ord(ch)`.

Вывод:

```
Hello, Kenga!
13
match!
H
```

## Урок 7 — списки

`examples/tour/07_lists.kenga`

Литерал `[10, 20, 30]`, индексация с нуля, `xs[i] = v` перезаписывает элемент.
Метода `append` нет: рост списка — встроенная функция `push(xs, v)`,
которая возвращает новый список, поэтому пишут `xs = push(xs, v);`.

Вывод:

```
3
20
60
[10, 20, 30, 99]
```

## Проверьте себя

1. Поменяйте урок 5 на рекурсивную сумму (`sum_to(n-1) + n`) — как в
   `examples/ml/kenga_seed_fib.kenga`.
2. В уроке 7 напишите функцию `max_of_list(xs) -> i64` через `while` и `if`.
3. Соберите строку `"1 + 2 = 3"` из чисел: понадобится встроенная `to_str(…)`
   (см. `tests/lang.rs::str_builtin`).
