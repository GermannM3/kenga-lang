Kenga 2.8 — язык для живого ИИ.

Без Rust:
  1) git clone https://github.com/GermannM3/kenga-lang.git
  2) скачай kenga-windows-x86_64.zip с Releases → kenga.exe в PATH
  3) kenga demo

Lite без Rust вообще (C99):
  bootstrap\build.cmd
  kenga run examples/selfhost/fact_lite.kenga

Chicken-egg lite из .kenga:
  bootstrap\rebuild-from-kenga.cmd

Сборка из исходников (опционально):
  cargo install --path . --force --locked
